# Improvement flags

Raised and resolved through the Continuous Improvement workflow ([`.claude/skills/continuous-improvement/SKILL.md`](../.claude/skills/continuous-improvement/SKILL.md)). Next ID: **FLAG-01**.

Status values: *open*; *fix applied, to check* (Continuous Improvement, *Blocking fix*); *accepted*; *rejected*. A closed flag moves from *Open* to the end of *Closed*.

## Proposed wording

Each flag's exact wording goes under its own heading: `### FLAG-nn (short title): <state>, <date>`. The state is *draft*, *confirmed*, *rejected*, or *applied as blocking fix*. Claude updates the state and the date when the state changes.
